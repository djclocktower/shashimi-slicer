# ColorSwatch

A square chip filled with an ACI color, followed by its name, as in the layer and color dialogs.

Provide `aci` (1–8), `size` (default 16) and `label` (defaults to the standard name; `false` hides it).

- The seven standard names are RED, YELLOW, GREEN, CYAN, BLUE, MAGENTA, WHITE; above 7 show the number.
