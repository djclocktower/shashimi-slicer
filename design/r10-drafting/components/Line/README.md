# Line

A line entity: an ACI color and a named linetype mapped to the `lt-*` dash tokens.

Provide `x1 y1 x2 y2`, `aci` (1–8, default 7) and `linetype` (continuous, dashed, hidden, center, phantom, dot, dashdot). `weight` sets a plotted pen width.

- Convention: visible 7, center 3 on `lt-center`, hidden 4 on `lt-hidden`, dimensions 2.
