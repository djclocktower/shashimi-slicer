# TitleBlock

The title block in the lower-right of a plotted sheet: title in Duplex, fields in Simplex, bold outer border.

Provide `title`, `company`, `number`, `rev`, `scale`, `sheet`, `drawn`, `date` and `units`.

- Everything uppercase; dates as MM-DD-YY.
- It belongs to the Plot theme; on Screen it inherits `ink` on black.
