# LayerTable

The layer-control table: name, On, Frozen, Color, Linetype in fixed columns inside a `field` well with a `panel-shade` header row.

Provide `layers` (`{name, color, linetype, on, frozen}`) and `selected`.

- Layer names are ALL CAPS, at most 13 characters here.
- Off and thawed are shown as "."; never use icons for state.
