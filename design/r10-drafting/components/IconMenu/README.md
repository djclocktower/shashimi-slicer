# IconMenu

The pictorial menu: a titled grid of vector slides with labels, the chosen tile boxed in `focus`.

Provide `title`, `columns`, `active` and `tiles` (`{pattern, aci, label}` for hatch swatches, or `{render(), label}` for any small SVG).

- Tiles are line drawings in ACI colors on `ground`, never bitmaps or photos.
- Labels are the object's system name in caps.
