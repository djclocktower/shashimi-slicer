# Hatch

The standard hatch patterns as 64x64 tiles: `ink` (#ffffff) 1px strokes on `ground` (#000000), the Screen theme. Pattern pitch is 16px (8px for DOTS), so any tile repeats seamlessly as a CSS background. Use them for icon-menu slides and section fills; in code prefer the `HatchSwatch` component, which recolors to any ACI color and follows the theme.
