# Glyphs

The drawing-area markers, each a 64x64 tile on `ground` (#000000).

- `ucs-icon.svg` — the coordinate-system icon: X and Y arrows, the W (world) mark and the plan-view square, in `ink` (#ffffff). Sits 16px in from the lower-left corner of every viewport.
- `crosshair-pickbox.svg` — the selection cursor: full crosshair with the 8px `pickbox` square, in `ink`. There is no arrow pointer inside the drawing.
- `grips.svg` — a selected entity: highlighted as a dashed line in `aci-6`, with 6px `grip` squares in `aci-5` (cold) and one hot grip in `aci-1`.
